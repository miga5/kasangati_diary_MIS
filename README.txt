Kasangati Dairy MIS - PHP + MySQL prototype

1. Install XAMPP (or WAMP) and start Apache and MySQL.
2. Copy this folder to htdocs (for example C:\xampp\htdocs\kasangati_mis_php).
3. Open http://localhost/kasangati_mis_php/install.php once. It creates the database
   "kasangati_dairy", the 9 tables from the ERD, and sample data.
4. Open http://localhost/kasangati_mis_php/login.php

If your MySQL root user has a password, change DB_USER and DB_PASS at the top of inc.php.
Demo logins are on the login page.
